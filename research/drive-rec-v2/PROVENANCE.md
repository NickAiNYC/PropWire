three-patch series is incorporated into the main repository, the preservation
manifest, reconstructed corpus, training split, criteria commit ordering, and
candidate evaluation scripts be verified. This document records that
verification, the lineage it verifies, one **disclosed incident** during this
session, and the incorporation recipe that protects the main repository's root
files.

## 3. Disclosed incident (2026-10-30, this session) — and recovery evidence

While running the first version of the Decision 2D test suite, a cleanup bug in
one test (`shutil.rmtree` aimed at a patched module attribute that had already
been restored) **deleted the working-tree `artifacts/` directory** mid-run.
Impact and recovery, all verifiable from git:

- **25 tracked artifacts** (all Decision 2C artifacts + the first
  `provenance_verification.json`): restored byte-exact from commit `fdf4ba9`
  via `git checkout HEAD -- …`; §11 hashes verified again after restoration
  (24/25 + the self-hash erratum above).
- **Gitignored joblib models** (`incumbent_model.joblib`,
  `isotonic_calibrator.joblib`): regenerated by re-running scripts 02 and 05;
  both regenerate **byte-identically** (SHA-256 `7257c181bf0571e2…` and
  `666fc5eaef36e481…` — identical to the first Decision 2D contract freeze), and
  all eight re-emitted prediction CSVs were verified **value-identical** to the
  committed versions (byte differences are gzip header timestamps only).
- **Untracked derived artifacts** (`selection_amplification_*.json`,
  `decision_2d_contract.json`): regenerated deterministically; script 10
  reproduced every number exactly; the contract was re-frozen before any quote
  acquisition (still true), with identical frozen-model hashes.
- The buggy test was rewritten to use `addCleanup` on the temporary directory
  only; the full suite (36 tests) passes against the recovered state.

Lesson recorded: the incident is exactly the failure mode the hash manifest and
git lineage exist for; recovery was provable because every artifact was either
committed or deterministically regenerable.

## 4. Incorporation into the main repository

The three-patch series was generated against a **root-level layout** — patch
0001 creates `README.md`, `.gitignore`, `LICENSES.md`,
`requirements-research.txt` at the repository root. Applied plainly to the main
repository, it **would replace the main repo's root README and .gitignore**
(Directive 2D §5: not without review).

Safe recipe (**tested on a scratch clone in this session** — all three patches
apply cleanly; root README/.gitignore untouched; only cosmetic
trailing-whitespace warnings). Note the patch paths must be absolute or
relative to the main repo, because `git -C` resolves them **after** changing
directory:

```
cd <main-repo>
PD=/path/to/propstein-tail-calibration-patches
git apply --check --directory=research/drive-rec-v2 "$PD/0001-chore-research-scaffold-Decision-2C-tail-calibration.patch"
git apply --directory=research/drive-rec-v2 \
  "$PD/0001-chore-research-scaffold-Decision-2C-tail-calibration.patch" \
  "$PD/0002-feat-research-rebuild-corpus-frozen-logistic-incumbe.patch" \
  "$PD/0003-feat-research-isotonic-tail-recalibration-on-2024-de.patch"
```

With `--directory=research/drive-rec-v2`, every path in the patches lands
inside the drive directory (`research/drive-rec-v2/README.md`,
`research/drive-rec-v2/research/00_download_data.py`, …): **no root file of the
main repository is touched** (the patches' own README/.gitignore also land
inside the drive directory, where they are inert). Review the result, then
commit. The alternative — merging this branch — is equally safe after the
restructure commit `fdf4ba9` because everything already lives under
`research/drive-rec-v2/`.

Either way, before incorporation the owner should still perform the §2
verification (`verify_provenance.py`) on the incorporated tree, per Decision 2D
§5: the supplied report is sufficient for a strategic decision, but is not an
independent code or artifact audit; the ZIP, patches, row-level predictions,
and Git history have not been inspected by the owner.
